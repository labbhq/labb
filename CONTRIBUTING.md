# Contributing to labb

👋 Thanks for your interest in contributing to labb!

We appreciate you taking the time to engage with this project. However, **we don't accept issues or pull requests at this time.**

## 💬 Please use GitHub Discussions instead

We use Discussions for all community interaction. Please visit our **[GitHub Discussions](https://github.com/labbhq/labb/discussions)** to participate.

This helps us keep everything organized and makes it easier for the community to participate in conversations.

## 🔒 What Happens to Issues and PRs?

Issues and pull requests created will be automatically closed.
