labb is built on the shoulders of excellent open source projects.

## Core Dependencies

- **[Django](https://www.djangoproject.com/)** — The web framework that powers everything
- **[Django Cotton](https://django-cotton.com/)** — Component syntax and template loader that makes `<c-lb.*>` possible
- **[daisyUI](https://daisyui.com/)** — Component classes and theming for Tailwind CSS
- **[Tailwind CSS](https://tailwindcss.com/)** — Utility-first CSS framework

## CLI and Tooling

- **[Typer](https://typer.tiangolo.com/)** — CLI framework powering the `labb` command
- **[Rich](https://rich.readthedocs.io/)** — Terminal formatting and output

## Icons

- **[Remix Icon](https://remixicon.com/)** — 2,800+ open source icons included via `labbicons`
